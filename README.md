## 🚀 Sobre o Projeto

Este é meu portfólio profissional desenvolvido com uma proposta diferente dos sites tradicionais.

A experiência começa em um **quarto 3D interativo**, com temática Cyberpunk/Tech, onde o visitante pode explorar o ambiente e interagir com objetos para descobrir informações sobre minha trajetória profissional, currículo, projetos e contatos.

O projeto combina desenvolvimento web, animações, interatividade e elementos de gamificação para criar uma experiência visual imersiva e intuitiva.

## 🌐 Demonstração

🔗 **Acesse o portfólio:** https://anderson123451.github.io/portfolio/

## ✨ Funcionalidades

### 🏠 Ambiente 3D Interativo
- Cenário com temática Cyberpunk/Tech.
- Efeito Parallax para criar sensação de profundidade.
- Animações em elementos do ambiente.
- Hotspots invisíveis que permitem interagir com objetos.

### 🖥️ Elementos Interativos
- **Monitor principal:** animação de código verde neon.
- **Monitor secundário:** feed simulado do LinkedIn.
- **Celular:** simulação de chamada recebida, com vibração e áudio.
- **Televisão:** mini-game de plataforma integrado ao ambiente.
- **Lousa e outros objetos:** acesso a conteúdos e informações profissionais.

### 🎬 Animações e Efeitos
- Modais com transições de zoom a partir dos objetos.
- Animações CSS em tempo real.
- Efeitos de Glassmorphism.
- Efeitos sonoros interativos.
- Controle de áudio conforme as permissões do navegador.

### 📱 Design Responsivo
- Layout adaptável a diferentes resoluções.
- Técnica de Letterbox com proporção 16:9.
- Posicionamento proporcional dos elementos interativos para preservar o alinhamento dos hotspots.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web nativas, sem dependência de frameworks.

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Layout, animações, efeitos visuais e responsividade |
| JavaScript Vanilla | Interatividade, eventos e manipulação do DOM |
| Canvas API | Desenvolvimento do mini-game 2D |
| Font Awesome | Ícones da interface |

### Recursos e Técnicas Aplicadas

**CSS3**
- Variáveis CSS (`:root`).
- Flexbox e CSS Grid.
- Keyframes e animações.
- Transformações 3D (`perspective`, `rotate` e `scale`).
- Glassmorphism com `backdrop-filter`.
- `clip-path` e `mix-blend-mode`.

**JavaScript**
- Manipulação do DOM.
- Controle de abertura e fechamento de modais.
- IntersectionObserver.
- Gerenciamento de áudio (`play` e `pause`).
- Histórico de navegação com `pushState`.
- Desenvolvimento de lógica de jogo utilizando Canvas 2D.
